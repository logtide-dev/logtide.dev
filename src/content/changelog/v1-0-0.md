## Coming in v1.0 Beta

First beta of the 1.0 line, hardening the platform before the stable cut:

- **Tenant Data Isolation Audit** — Every backend data-access path audited and hardened for multi-tenant isolation
- **Metering & Capability System** — Per-organization usage measurement, feature gates, and enforceable limits/quotas (ingestion, spans, storage) — the foundation for plan tiers without changing OSS behavior
- **Lifecycle Hooks** — A typed extension surface to observe, mutate, or reject ingestion, query, alert-evaluation, and webhook-dispatch without forking
- **Outbound Webhook Delivery** — Reusable delivery system with HMAC signing, retry with backoff, a dead-letter queue, and centralized SSRF protection
- **Audit Log Primitive** — Typed actions, actor types, outcomes, and per-organization retention with daily cleanup
- **Scheduled Digest Reports** — Email-based summaries on a configurable schedule
- **Fail-Closed PII Masking** — Records that fail masking are rejected before storage instead of being stored unmasked
- **Request Context Propagation** — End-to-end request context across the backend
