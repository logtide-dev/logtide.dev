A maintenance release built from feedback on the log explorer. The biggest change is speed: on ClickHouse, projects whose logs carry request or response bodies in their metadata could wait 20 seconds for facets. No migrations.

### Added

- **Host resource metrics from the hardware agent**: agent 1.1.0 (`logtide/hw-agent`, released separately) adds a `system` collector, on by default. It sends CPU utilization per state, load average, memory and swap, filesystem usage, disk and network throughput and uptime as `system.*` metrics, so a host shows up in the Metrics Explorer next to its `hw.*` health signals. If you set `LOGTIDE_HW_COLLECTORS` explicitly, add `system` to the list. In Docker, mount the host root for filesystem usage. The compose file has the line ready to uncomment. The full list is in the [Hardware Health docs](/docs/hardware-health/#system-metrics).

### Changed

- **Log context opens on the log**: the context dialog loads 25 logs before and after the one you picked, and now scrolls to it straight away instead of starting at the top. Each row has a single "Copy log as JSON" button and a "View JSON" expander with the same highlighted JSON as the log details panel.
- **Actions in the JSON view**: "View context" and "View exception details" are available from the JSON tab of log details too, not only from Details.
- **Tooltips on log detail buttons**: the icon buttons on each field (copy value, copy field path, show only, hide, add as column) now say what they do when you hover or focus them.
- **Facets sample size**: facets count the newest 20,000 matching logs instead of 100,000. The top values are the same in practice, and the panel tells you when a sample was used.

### Fixed

- **Slow facets and log list on ClickHouse**: when logs carry large metadata, such as request or response bodies, facets and the first page of logs read and sorted the metadata of every scanned log before cutting the sample or the page. They now pick the logs from the time, id and filter columns first and read full rows only for those. On a production project with about 40 KB of metadata per log, facets went from 21 seconds to under 2, and the log list from about 3 seconds to 65 milliseconds.
- **Log detail keys breaking mid-word**: on narrow screens, metadata keys in the Details view wrapped in the middle of a word. They now wrap between words, after `.`, `_` and `-` and at camelCase boundaries, and never make the panel scroll sideways.
- **Sidebar and scrollbars**: the line under the logo now lines up with the header's bottom border, and every scroll area in the app uses a thin scrollbar in the theme colors instead of the wide native one.
